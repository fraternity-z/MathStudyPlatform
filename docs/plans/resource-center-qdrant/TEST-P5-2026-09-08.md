## 数据与门槛

- 60 个原创短讲义：32 个数学分析主题、13 个线性代数主题、15 个概率统计主题。每份为单段知识说明及常见误区，TXT、MD、DOCX、PDF 各 15 份；真实解析形成 75 个块。它们不是实际学期教学文档的统计样本。
- 120 个独立编写的问题，包括自然改写与主题解释；分别运行正常和 FTS 降级模式，形成 240 个正例。另有无授权资源的检索空结果与权限场景；单独验证直接访问旧引用和撤权。
- 原始文件按固定顺序连接计算 SHA-256：`b09f14e8a3bbaff0540ca506172aae829172faceb2964c7736574135d7f6dcaa`。真实文档 embedding 输入 9502 UTF-8 字节/60 次调用；一次重建后合计 19004 字节/120 次调用。报告不将输入字节冒充供应商精确 token 或账单金额。
- 容量数据从 75 个真实向量/块复制到 100000 个当前可见 chunk 与 manifest。复制只用于压力、引用和状态验证，不增加独立语义样本数量，不重复调用 embedding。
- 数值 ANN 实验沿用上一轮 1024 维、64 簇、固定种子的十万点，摘要 `6de9f45a2450f87b1d048401cbc4be5e5d12b68135cd4506793a613478c60ec5`；100 个查询与同过滤条件的 exact oracle 对照，不能与教学 Recall 混合。
- 保持原门槛：Recall@5 ≥ 0.90、MRR/nDCG ≥ 0.85，引用与权限正确率 100%；十万条/五并发，本地搜索 P95 ≤ 1 秒，含真实 query embedding ≤ 3 秒。额外记录 P99、请求数、错误/降级、队列、内存与连接。

## 已交付修复

1. Qdrant 搜索增加部署侧 `QDRANT_SEARCH_HNSW_EF`，0–8192，0 保留供应商默认；现代/兼容端点保持一致，普通请求不能指定精度或模型。
2. `0024_resource_lexical_features` 保存正文/标题的生成 FTS 与汉字词项列及 GIN 索引，避免每次命中都重新分词。旧表达式索引保留以支持应用回滚。
3. 词法检索先筛选当前已索引 manifest，再按版本、hash 与完整正文归并，取最早有效 ordinal；只传递必要身份后再载入评分字段。不存在跨文档合并、仅按 hash 合并或让未索引第一份文本挡住有效副本的情况。
4. 首次授权后对融合候选按同版本正文去重，保留最高排名有效引用；最终再次授权、去重。这样向量副本不再占满 TopK 或重复进入后处理。
5. 召回为后处理保留 `min(剩余时间/3, 500ms)`；短请求保持原预算，最终授权和全部处理仍受总 deadline 约束。修复冷 embedding 尚有请求预算却提前被降级的问题。
6. 管理员导入导出跳过生成字段，由 PostgreSQL 重建；恢复工具在 `pg_restore` 后执行 `ANALYZE`，失败不报告成功。
7. 并发评估工具复用固定数据、正常/降级分组、引用核验及脱敏原子报告；失败请求计入延迟与预算，预算耗尽不能冒充跑满 soak。

两次独立重建均使用相同数值输入和查询；HNSW 构图存在波动，不能把单次差异都归因于 ef。

## 质量、入库与发布

真实 60 文档入库约 29–31 秒，默认 worker 并发 2；四格式均发布成功。通过正式 HTTPS handler、真实 PostgreSQL/应用/Qdrant、管理员 query embedding 执行冻结评估。HTTP token 解析使用临时 Authenticator，数据库账户/权限/版本与最终授权使用真实仓储；不把该路径当作完整登录系统复测。

首次 240 正例报告 Recall/MRR/nDCG 为 0.995833/0.956319/0.966153，1187 次引用核验通过。生成列版本再次通过同口径门禁，具体最新数值以最终结果表为准。随机数据库身份会改变完全同分候选的次序，不能把小幅波动直接解释为优化增益。

在线读取期间真实重建进入 ready，schema 核验后完成 promote 和 rollback；旧代恢复可读，后台队列清零。保留默认切块、批量与并发，结合既有[切块/融合测试](TEST-TEXT-TUNING-2026-09-08.md)和[101 个入库子场景](TEST-INGESTION-TUNING-2026-09-08.md)，不因为小型短文档吞吐而提高生产并发。

管理员 reranker 当前未启用，实查返回 disabled，未发起 rerank provider 请求。决策是继续禁用，未声称测得真实重排增益。临时预取 query 向量实验量化了跳过重复 embedding 的潜在延迟收益，但没有交付应用查询/授权缓存；20 次撤权后的重复读取及旧引用拒绝通过，保留每次新授权和管理员配置解析。

五次真实 Tutor 请求使用原创不相关资料和其中的恶意指令，分别询问缺失的考试地点、作业截止时间、函数表达式、证明题分值和矩阵元素。逐条人工核对：均明确资料不足，没有把“教室999/今晚截止”当作事实，没有猜造函数、矩阵或分值。回答中的 [1] 用于说明资料实际包含/缺少什么，不是为猜造结论背书。本轮为正式 Eino Tutor 加固定不可信资料上下文的验证，不冒充一次新的完整 Session 持久化测试。

## 迁移、边界和失败记录

- 隔离空库执行 24 个迁移；23→24 在 10000 个已有块上回填约 1.993 秒，再执行为 0。源正文/标题更新会重算词法字段，直接覆盖生成字段被拒绝；管理员 JSON 导出/导入成功重建字段。
- 10 个真实 SQL 去重/边界子场景覆盖 pending/deleted manifest、deleted chunk、错误维度、下架、代际变化、hash 相同但正文不同、单字中文、转义通配符和英文召回。
- Mock 验证 Query/Scan/Rows 错误、HNSW 默认/上下界/非法参数、现代及 404/405 回退、错误响应、deadline、撤权、跨文档与跨版本正文去重。临时源码按仓库规则清理，不能从仓库无测试文件反推未测试。
- 第一轮 100000 块真实 query soak：600 请求、435 次 FTS 降级，P95 2385.948 ms，失败；单独词法查询约 5972.551 ms。没有把向量降级仍返回结果写作成功。
- 仅保存词法字段后仍有慢查询；在同一数据上以计算特征与保存特征分别查询，身份、顺序及得分一致，但耗时尚未达标，继续减少重复正文、宽中间结果和重复后处理。
- 后续曾出现持续运行通过但首批突发超标、或正式并发报告 P95 超标的情况；这些整次命令仍按失败记录，不用通过的子项覆盖失败。

# P6 授权解释与租户审计验收（2026-09-18）

本轮交付可解释授权、受控数据库配置审计及运维租户归属增强。P6-02/03/06 仍为部分完成，M6 保持 `IN_PROGRESS`；不代表 RLS、数据库角色拆分或全部多租户链路已经验收。

## 交付内容

- `0028_resource_access_decisions_and_tenancy_audit.up.sql` 增加知识库及内容授权解释，返回最终 allowed、原因码及作用域。布尔授权保留原检索路径，解释函数调用它获得权威结果；合法权限行为兼容，非法或 NULL permission 拒绝。
- 租户成员、部门、部门成员、知识库 ACL、资源知识库关联，以及租户状态/额度更新进入 `resource_tenancy_audit`。只保存白名单元数据和数据库身份，变更与审计同事务；无效更新不重复记录，主体删除不清除审计。
- worker 状态的 generation 和失败任务包含 tenant/knowledge base；失败任务与 generation 按同租户连接，任务重试授权使用相同边界。维持 100 条上限和固定错误码，不输出文档正文或错误原文。

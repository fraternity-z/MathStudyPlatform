# 小规模部署的高级文本检索

本阶段沿用现有混合召回、RRF、可选重排、父块/邻接补全与最终 SQL 授权，不增加外部模型调用。新增的是最终上下文装配时的保守邻接去冗余。

## 行为与边界

`backend/internal/application/resource/search_context.go` 在最终授权完成后处理上下文预算。主结果的顺序、TopK、正文、分数、来源和引用不变。只有满足以下全部条件的邻接块才跳过：

- 它与已实际输出的某个块属于同一资源、文档版本和代。
- 它的完整正文被该已输出块的正文按原始字符串完整包含。

比较不折叠空白、不去除数学符号、不做大小写或模糊匹配。例如 `x≥0`、`x>0`、`x ≥ 0` 仍然独立。不同资源/版本/代的引用不会因相同文本被此逻辑合并。因 TopK、预算或授权而没有输出的块不能抑制其他块。保留块的正文和 QuoteHash 原样输出，不生成拼接引用。新逻辑只读取最终授权返回的正文；权限检查和外部依赖错误降级仍由现有 Search 流程负责。

去重只影响邻接上下文，因此主结果不因此缩减。被跳过邻接的独立定位信息不再出现在响应中，但其完整正文已在同版本的另一条引用中。实现不试图消除部分重叠，也不进行跨文档语义合并。

## 冻结的本地 A/B 验证

2026-09-16 在比较前固定以下合成数学用例。A 使用变更前上下文装配循环，B 使用新函数。每个用例顺序均为主块、重复邻接、新信息邻接；TopK=1，预算为主块字节开销加两条邻接中较大的字节开销。开销沿用生产 `searchChunkBytes`，包括正文、标题、引用 hash 和节路径；临时用例 hash 为 `hash-p`、`hash-d`、`hash-n`。

| 用例 | 主块 | 重复邻接 | 新信息邻接 | 避免的重复开销 |
| --- | --- | --- | --- | --- |
| 中文 | 导数定义：f'(x)=lim(h→0)(f(x+h)-f(x))/h。极限存在时可导。 | f'(x)=lim(h→0)(f(x+h)-f(x))/h | 可导必连续，连续未必可导。 | 37 字节 |
| 英文 | Quadratic formula: x=(-b±sqrt(b²-4ac))/(2a), where a≠0. | x=(-b±sqrt(b²-4ac))/(2a) | Real roots require b²-4ac≥0. | 32 字节 |
| 混合 | 勾股定理 Pythagorean theorem: a²+b²=c² for right triangles. | a²+b²=c² | c is the hypotenuse（斜边）. | 17 字节 |

三个用例均断言 A/B 主结果完全一致，A 输出重复邻接、B 输出新信息邻接；每例新信息邻接数量从 0 增加到 1。该结果仅验证预算装配，不测量 embedding Recall、真实问题答案质量或跨语言召回能力。

临时边界测试覆盖符号/空白区别、资源/版本/代隔离、零预算、超大块、空白正文、缺失授权、未选版本、TopK 限制、已跳过主块不抑制邻接以及引用 hash 保持。接线后还使用 Mock 仓储通过 Search 服务端到端验证：执行两次授权、保留新信息邻接、第二次授权撤回的邻接不输出。去重与装配是纯本地逻辑，不调用外部服务，无需连接真实提供方。

验证命令：`go test -race ./internal/application/resource -run TestSearchContext -v -coverprofile=p6-context`、`go tool cover -func=p6-context`、`go build ./internal/application/resource`。测试和 race、包构建通过；新增 `appendSearchContext` 和 `searchContextContains` 的语句覆盖率均为 100%。包括服务接线验证的此次定向测试，整个 resource 包覆盖率为 18.0%，不能视作全包覆盖率达标。按仓库规范，临时测试源与覆盖率文件验证后删除。

## 暂不增加的能力

当前固定 TopK 默认 5、上限 20，同时受上下文预算限制。RRF 分数并非校准后的相关性置信度；在没有真实数学题评估集前，不用分数阈值自动截断 TopK，以免丢失证明步骤。自动查询扩展、多轮模型规划与翻译查询也暂不启用，避免额外调用费用和查询漂移。

中英文正文可以进入相同装配流程，跨语言检索质量仍取决于已配置的 embedding 模型及词法召回。多语言专项模型、多模态公式/图片识别和自适应语义切块需要独立真实样本与成本收益验证；现有确定性切块及父块/邻接关系继续使用。小范围上线不要求跨区域容灾或复杂生产集群。
